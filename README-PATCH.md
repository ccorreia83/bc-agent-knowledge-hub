# Patch v3 - URL sem extensão para Copilot Studio

Copie o conteúdo deste ZIP para a raiz do repositório, substituindo os ficheiros anteriores, e faça commit/push.

Esta versão mantém a página consolidada, mas publica-a com o URL sem extensão exigido pelo Copilot Studio:

`https://mypartnerts.github.io/bc-agent-knowledge-hub/knowledge-all/`

Depois do deployment:

1. Abra o URL acima no browser.
2. No Copilot Studio, adicione esse URL, incluindo a barra final.
3. Remova a tentativa anterior terminada em `.html`.
4. Guarde, aguarde a indexação e publique o agente.
