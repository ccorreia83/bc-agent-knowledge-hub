## Mandatory workflow

1. Use the role from the invoking agent mission.
2. Classify the request by domain.
3. Open the role routing file.
4. Open only the relevant domain and source files.
5. Consult the final authoritative source or live tool.
6. Cite the final source, not only this Hub.
7. State version, localization, deployment, and source coverage when material.
8. Separate `DOCUMENTED`, `IMPLEMENTED`, `OBSERVED`, `INTERNAL`, and `INFERRED` conclusions.

2. Confirmed internal mappings and decisions.
3. Current internal documentation.
4. Official Microsoft documentation.
5. Relevant Microsoft-maintained source code for the inspected revision.
6. Microsoft training and samples.
