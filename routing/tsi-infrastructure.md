# TSI and infrastructure routing

Use for SaaS/on-premises administration, service tiers, SQL, Windows, Azure, identity, networking, certificates, email, telemetry, upgrades, backup, and performance.

- BC administration and deployment -> Business Central Developer and IT Pro.
- OAuth, S2S, App Registrations, Conditional Access -> BC docs plus Microsoft Entra.
- Containers and artifacts -> BcContainerHelper.
- Azure infrastructure -> Azure documentation.
- Windows, AD DS, DNS, IIS, TLS -> Windows Server documentation.
- Exchange Online/Server, SMTP, connectors -> Exchange documentation.
- CI/CD -> AL-Go.

Read and diagnose before changing. Upgrade guidance must include prerequisites, backup/rollback, dependency order, schema synchronization, validation, and outage assumptions.
