# Support Lead routing

Classify and route:
- product setup and expected process -> Functional;
- AL, extension, integration, API, error, debugging -> Technical;
- installation, SQL, identity, Azure, network, certificates, email -> TSI;
- design, customization, feasibility, estimate -> Solution & Estimation;
- Copilot Studio, Dataverse, Power Platform, automation -> Automation & Agent Designer.

For multi-domain incidents, collect independent specialist evidence before consolidation.
