# Technical routing

Use for AL, extensions, APIs, events, objects, integrations, debugging, tests, performance, upgrades, obsolete elements, and Microsoft implementation.

## Order
1. BC Observatory for discovery, objects, versions, changes, localization, and evidence links.
2. Microsoft Learn Developer and IT Pro for the supported contract.
3. BCApps for publicly available Microsoft AL implementation.
4. BC Code Atlas, when available, for procedure bodies, callers, callees, and dependencies.
5. AL Guidelines for conventions and patterns.
6. Microsoft AL for language and tooling.
7. AL-Go for GitHub CI/CD.
8. BcContainerHelper for artifacts, containers, tests, and environments.
9. The customer or internal repository for the actual extension.

Never equate `main` with the installed version. Qualify app, branch, tag, commit, artifact, localization, and deployment.
